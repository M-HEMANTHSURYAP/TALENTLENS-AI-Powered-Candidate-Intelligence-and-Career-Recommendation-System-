# 🧠 TALENTLENS

## 🚀 AI-Powered Candidate Intelligence & Career Recommendation System

TALENTLENS is a web-based candidate intelligence and career guidance platform designed to help users understand their technical skills, identify skill gaps, analyze resumes, explore suitable career paths, and practice technical interviews.

The project brings **skill analysis, resume intelligence, career recommendations, and interview evaluation** together into one platform.

> 🚧 **Development Status:** TALENTLENS is currently under active development. The core functionality is implemented and working, while further improvements, refinements, and additional features are planned for future versions.

---

# 🎯 Project Overview

Choosing the right career path can be difficult when candidates are not sure about their current technical skills, missing skills, resume quality, or interview readiness.

TALENTLENS is designed to help candidates get a clearer picture of their current capabilities and areas for improvement.

With TALENTLENS, users can:

- 🧩 Analyze their technical skills
- 📊 Identify missing skills for a selected career role
- 🎯 Calculate a career readiness score
- 📄 Upload and analyze a resume
- 🔍 Detect technical skills from a resume
- 🧠 Compare detected skills with a target career
- 🚀 Get personalized skill recommendations
- 💬 Practice technical interview questions
- 📝 Evaluate interview answers
- 📈 Receive an interview readiness score
- 💡 Get feedback based on their technical responses

The main goal is to provide candidates with a structured understanding of **where they currently stand and what they can improve.**

# ✨ Key Features

## 🎯 Candidate Skill Analysis

Users can enter their:

- 👤 Name
- 📧 Email
- 💼 Target career role
- 🛠️ Existing technical skills

TALENTLENS compares the provided skills with the requirements associated with the selected role.

The system identifies:

- ✅ Matching skills
- ❌ Missing skills
- 📊 Career readiness score
- 📚 Recommended learning areas

---

## 📄 Resume Intelligence

Users can upload a PDF resume.

TALENTLENS extracts text from the uploaded resume and analyzes it to identify technical skills.

The detected skills can then be used for further career analysis.
